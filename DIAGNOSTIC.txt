MW4 RAY RECONSTRUCTION - DIAGNOSTIC 2
TARGETED SUBSURFACE SCATTERING SHADER CAPTURE
NOT A RELEASE. NOT A NOISE FIX.

This temporary Beta 2 build is for the player whose previous log identified
shader c6c858a6310ca6a2 (56,352 bytes). It saves that exact shader so we can
compare it offline. Keep the same settings and use the same noisy scene.
No capture hotkey or repeated hardware/settings tests are needed.

CAMPAIGN ONLY
Use only with sp26-cod.exe. Do not use in multiplayer, DMZ or COD HQ.
Those modes are outside this test and may use anti-cheat. No assurance
against anti-cheat action is provided.

INSTALL
1. Fully close the game and COD HQ.
2. In the sp26 folder containing sp26-cod.exe, back up mw4-rr.addon64 and
   mw4-rr-dxcompiler.dll somewhere OUTSIDE the game/addon folders.
   Do not leave a renamed .addon64 backup there: ReShade could load both.
3. Copy the two files with those same names from this ZIP into sp26,
   replacing the existing copies. Keep your existing ReShade installation,
   configuration and graphics settings. Do not install a second addon copy.

RUN ONCE
4. Launch the campaign and open ReShade. Look for the tab
   "MW4 RR - DIAGNOSTIC 2" and the heading "DIAGNOSTIC 2 (NOT A RELEASE)".
   If absent, stop: the diagnostic is not loaded. Send ReShade.log.
5. Load the SAME mission/scene where the noise occurred. Keep your previous
   graphics settings, especially VRS and ray-tracing quality, unchanged.
   Ensure Ray Reconstruction and the Subsurface Scattering Guide are enabled.
6. Wait about 30 seconds. Capture is automatic. The diagnostic capture status
   should say "SAVED - ready to send with ReShade.log". The normal guide may
   still say waiting: this build does not add support for the variant yet.
   Capture can finish during loading; SAVED does not itself mean the guide works.
7. If SAVED never appears, wait up to 60 seconds in the scene and take a panel
   screenshot anyway. FAILED means a file-write problem; send the log for the
   error. Do not change settings or run the game as administrator for this test.
   Reach the scene within 10 minutes; observation stops after that period.
8. Exit normally. Copy ReShade.log before launching again, as it may be replaced.

SEND BACK PRIVATELY
- The folder named MW4-RR-DIAGNOSTIC-2-... inside sp26. The exact file path is
  shown in the diagnostic panel and ReShade.log. It contains one file:
  subsurface-scattering-variant.cso (56,352 bytes, about 55 KiB).
- ReShade.log from that same run.
- A screenshot of the diagnostic panel and the mission/scene name.
If there is no capture folder/file, send the log and panel screenshot anyway.
Zip the capture folder and log together if convenient. The .cso file is data,
not a program to launch. It contains a game-provided shader; send it privately
for debugging, not to Nexus, a public issue, or a source repository.

RESTORE AFTERWARD
With the game and COD HQ closed, restore your two backed-up runtime files.
Keep the captured folder until it has been received; then it can be removed.

WHAT THIS BUILD DOES
- Copies only the exact identified shader, once per process; no shader search
  dump, screenshots, GPU readback, rendering modifications or automatic upload.
- Owns a copy before the game's pipeline callback returns, then saves it from
  the existing runtime callback. It never retains a borrowed shader pointer.
- Writes a unique per-run folder and does not overwrite earlier captures.
- Keeps the previous bounded recognition metadata in ReShade.log. It is not a
  performance benchmark; CPU logging and the small file write can add overhead.
- The log may contain local paths, hardware details and graphics settings.
- CPU tests and compilation are checked before distribution. It still needs
  this in-game run on the recipient's setup. No game shader is included in ZIP.
