MW4 RAY RECONSTRUCTION - BETA 2
By Fever308

ReShade addon for the MW4 campaign executable sp26-cod.exe.
Ray Reconstruction, the Transparency Guide, and the Subsurface Scattering
Guide are enabled by default. The initial Ray Reconstruction preset is F.
Your choices are saved between sessions.

Beta 2 is a beta mostly in name. In my own playtesting, roughly 98% of the
noise I was seeing is gone, but there may be issues I haven't caught yet.
That is my personal experience in gameplay, not a measurement; results can
vary by scene, hardware, and settings.

REQUIREMENTS

- Windows x64 and an NVIDIA RTX GPU with working DLSS Ray Reconstruction.
- The MW4 campaign with ray tracing enabled.
- ReShade 6.8.0 with full add-on support. Other versions have not been
  verified. ReShade itself is not included.
- A working NVIDIA Ray Reconstruction runtime (nvngx_dlssd.dll) loaded
  by the game. Keep the existing DLL when installing this addon; you do
  not need to replace it just to install the mod. NVIDIA's runtime is
  not included in this download. Testing used version 310.7.128.0;
  the addon does not enforce that exact version, and other versions
  have not been verified.
- Microsoft Visual C++ x64 runtime.

This package is for the campaign. Multiplayer, DMZ, and COD HQ are not supported.

INSTALLATION

1. Fully close the campaign and COD HQ. Back up your addon files and game
   configuration before making changes.
2. Find the campaign's sp26 folder. A Steam example is:
   C:\Program Files (x86)\Steam\steamapps\common\Call of Duty HQ\sp26
   Your Steam library may be on another drive.
3. Install addon-enabled ReShade for sp26-cod.exe using DirectX 12 if you
   do not already have a compatible installation.
4. Copy ONLY these two runtime files from this ZIP beside sp26-cod.exe
   and the campaign's ReShade DLL:
     mw4-rr.addon64
     mw4-rr-dxcompiler.dll
   Keep both files together. The companion DLL is needed by the addon.
5. Load only one copy of this RR addon. When updating, remove the previous
   version from the addon directory before installing.
   Do not remove unrelated addons or replace unrelated DLLs.
6. Apply the configuration below before launching the game.

REQUIRED GAME CONFIGURATION

With the game and COD HQ fully closed:

1. Press Win+R, paste the following path, and press Enter:
   %LOCALAPPDATA%\Activision\Call of Duty\players
2. Back up s.1.0.cod26.txt. Right-click the original file > Properties.
   Clear Read-only and select Apply so that you can edit it.
3. Open the original file in a text editor. Find each EXISTING entry by
   the name before its @ suffix. Change only its value after the = sign.
   Keep the entire @ suffix and the comments. Do not paste new duplicate
   keys or use the example suffix below as your own.

   Setting name                 Required value
   ------------                 --------------
   MotionBlur                   Off
   WeaponMotionBlur             false
   EnableVelocityBasedBlur      false
   DofEnable                    Off
   DofWeaponDisable             true
   DofWorldDisable              true
   AATechniquePreferredMP       DLSS
   DLSSModeMP                   DLSS
   DLSSModelUI                  TRANSFORMER
   DxrDenoiser                  DLSS Ray Reconstruction
   DynamicSceneResolution       false

   "Script" depth of field and "Cinematic Only" motion blur are NOT off.
   Use the values above for all six blur/depth-of-field entries.

   DxrMode has entries with different meanings. The @0 entry
   uses On, while the @1 entry selects a ray-tracing quality such as High.
   Follow the allowed values in each entry's comment; do not set both to On.

   VRS can be true or false. Keep exactly one VRS entry. VRS on is supported.
   Enhanced FOV must be OFF in the game's settings. Set it before making
   the config read-only. A numeric normal FOV setting is not the same option.

4. Choose DLSS quality using the EXISTING DLSSPerfModeMP entry:

   Config value          Quality choice
   ------------          --------------
   Ultra Performance     Ultra Performance
   Maximum Performance   Performance
   Balanced              Balanced
   Maximum Quality       Quality
   Native Resolution     Native resolution

   Example of the change (keep YOUR actual suffix and comment):
   Before: DLSSPerfModeMP@... = Maximum Performance // ...
   After:  DLSSPerfModeMP@... = Balanced // ...

   Quality changes require a full game restart in this beta. The in-game
   selector may be greyed out or display Filmic SMAA; use this config entry.

5. Save the file. Right-click it > Properties > check Read-only > Apply.
   Read-only is REQUIRED: the addon will not enable RR if this file is writable.
   To change quality later, close the game/HQ, clear Read-only, edit the value,
   save, and restore Read-only before launching again. Read-only can also
   prevent other game settings from being saved to this file.

CONTROLS AND STATUS

Open ReShade and select its Add-ons panel. Find MW4 Ray Reconstruction.

- Ray Reconstruction, Transparency Guide, and Subsurface Scattering Guide
  have separate checkboxes. Both guides require Ray Reconstruction.
- RR preset choices: Default, D, E, F. F is the initial default.
  Presets can be changed live. Applying one may take a moment or briefly hitch.
- F8: toggle Ray Reconstruction.
- F9: toggle the Transparency Guide.
- F11: toggle the Subsurface Scattering Guide.
- F8, F9, and F11 do nothing while Ctrl or Alt is held.

More checkboxes, all on by default:
- Transparency albedo blend: keeps texture seen through glass, particles,
  and refraction steadier while moving.
- Specular hit distance: gives RR the game's specular ray hit distances.
- Weapon depth: the weapon and hands keep their own depth instead of
  looking like a flat card to RR. Changing it restarts RR briefly.
- Water responsivity mask: less smearing on running water (preset F only).
- Replace the game's DLSS upscaling: RR takes the place of the game's
  DLSS Super Resolution pass when it can. When it can't, the game's pass
  runs and RR runs after it.

Third-party DLSS add-ons such as DLSS5 NR work alongside RR with all of the
above on. They then process RR's output, so pre-rendered cutscenes are no
longer filtered through them. DLSS5 NR is the add-on that was tested.

The status panel shows whether each feature is working:
- Off: disabled.
- Active: currently working.
- Waiting: switched on, but currently unavailable in the scene.
- Error: the addon encountered a problem; see troubleshooting below.

CURRENT BETA LIMITATIONS

- Enhanced FOV, motion blur, and depth of field must remain disabled.
- Some noise or blotches can remain on skin, clothing, and other materials
  with Subsurface Scattering, particularly during movement.
- Transparency coverage varies by scene. Some surfaces may still show noise,
  loss of detail, or Waiting status. The guide is not guaranteed on every surface.
- The image may briefly look softer or noisier when RR is unavailable.
- Under heavy GPU memory use (for example with DLSS5 NR at high output
  resolutions), some guides may show Waiting until memory allows them.
- DLSS quality requires a config edit and restart. RR presets switch live.
- Game updates may require an addon update.
- If RR becomes unavailable after changing graphics settings, restart the game.
- This beta is still being tested. Compatibility and image quality can vary
  by mission, hardware, settings, and other addons. An FPS increase is not
  guaranteed.

IF RR DOES NOT ACTIVATE

Confirm the settings file is read-only, contains one valid VRS entry, and uses
the required DLSS/ray-tracing settings. Check ReShade's Add-ons panel for the
reported state and make sure only one RR addon is installed. For a bug report,
include the campaign ReShade.log, panel screenshot, game/driver versions,
GPU, output resolution, DLSS quality, affected mission, and reproduction steps.
Save the log after the affected run before launching again.

UNINSTALL / ROLLBACK

Close the campaign and COD HQ. Remove mw4-rr.addon64 and mw4-rr-dxcompiler.dll
from the campaign folder. Restore your own backups if rolling back, including
your game configuration if desired. Leave unrelated addon files intact.
To also remove the locally prepared shader cache, delete the folder
%LOCALAPPDATA%\MW4-RR\ShaderCache (paste it into the Explorer address bar).
